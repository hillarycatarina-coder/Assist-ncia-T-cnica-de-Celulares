 Sistema de Assistência Técnica de Celulares

Sistema desenvolvido em Python para gerenciar uma assistência técnica de celulares.

 Funcionalidades
- Cadastro de clientes.
- Gerenciamento de aparelhos.
- Agendamento de serviços.
- Sistema de login.

 Tecnologias utilizadas
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

 Objetivo
Facilitar o gerenciamento de clientes, aparelhos e agendamentos de uma assistência técnica de celulares.
